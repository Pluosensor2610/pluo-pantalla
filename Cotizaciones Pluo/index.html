Clientes y productos se pueden sincronizar leyendo un Google Sheet público vía Sheets API + API Key. Requiere que el Sheet tenga permisos de "Cualquiera con el enlace puede ver".

Google Apps Script — Guardar cotizaciones

Una API Key sola no permite escribir en Sheets. Publica un Google Apps Script vinculado al Sheet como "Web App" (acceso: cualquiera) que reciba un POST y agregue la fila. Pega aquí la URL del Web App para que cada cotización generada se envíe automáticamente además de guardarse en el iPhone.
